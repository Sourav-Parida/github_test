ASSESSMENT / PRACTICAL WORK DESCRIPTION

Purpose
--------
This document summarises the assessments and practical exercises completed while progressing through the Learnlytica curriculum. The work covers backend programming concepts, software engineering practices, machine learning, deep learning, computer vision, natural language processing, and modern generative AI topics.

Backend and Application Assessments
------------------------------------
Day 9-11: TaskFlow application exercises

Day 9 covered database and application data-handling concepts:
- SQLAlchemy DeclarativeBase models and in-memory SQLite databases.
- Inserting and reading task records and converting ORM objects into plain dictionaries.
- Parameterised filtering of tasks by status.
- SQL joins and aggregate queries for counting open tasks by project.
- Batch create, update, and delete operations.
- Input validation and structured error responses.
- Typed HTTP-style error bodies for cases such as "not found".

Day 10 covered API and application reliability concepts:
- Safe sanitisation of user-entered tag names.
- Cache-key construction for task queries.
- CORS header construction.
- PBKDF2 password hashing and secure password verification.
- A TTL cache-aside implementation.
- Structured JSON log records containing request context and outcome.

Day 11 covered service and security concepts:
- JWT access-token creation using HS256.
- JWT claim verification, expiry checking, and role-based validation.
- Counting tasks by status.
- Repository and cache interactions for cache-first task reads.
- Dependency injection using a repository and clock.
- Computing overdue tasks and parameterised result summaries.
